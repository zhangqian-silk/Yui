# T09｜插件开发工具与受权执行

硬依赖：T02、T05。

## 交付目标

提供独立插件开发、验证和激活路径，使能力可由开发者或 Agent 在明确授权环境中创建。

**完成状态：** 独立包无需修改 Yui 源码即可提供能力；验证与实际激活的产物和权限一致。

## 责任范围

- 实现 create／validate／activate／disable。
- 区分数据型贡献、可信内建和授权可执行扩展。
- 使构建、测试和运行使用明确环境；初始化只注册不做业务动作。

## 可独立分工的工作

1. 建立 manifest 和最小模板。
2. 接入开发环境与验证报告。
3. 实现原子注册及权限边界验证。

这些分工供 Leader 判断，不要求按步骤建立 WorkItem。紧密耦合的实现应由同一责任单元完成。

## 不在范围内

- 不建设市场、通用签名体系或新的沙箱平台。
- 不把 manifest permissions 当作实际隔离。

## 完成证据

- 验证 A 产物不能静默激活 B 内容。
- Task-local 插件不能自动获得全局权限。
- 失败激活不留下半套能力，不破坏当前 Provider。

验收场景：S28、S29、S31、S34、S45。场景定义见[统一验收说明](../../reference/acceptance-scenarios.md)。
