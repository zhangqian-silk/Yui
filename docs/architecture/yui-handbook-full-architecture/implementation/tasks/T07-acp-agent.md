# T07｜ACP 接入与第三 Agent 验证

硬依赖：T04。

## 交付目标

用一个真实支持 ACP 的 Agent 验证 Endpoint 的通用边界，并让协议逻辑可被多个产品复用。

**完成状态：** 新增 Agent 主要由产品启动预设和协议适配完成，Task 与 Controller 不增加产品分支。

## 责任范围

- 选择并记录被验证的 CLI、协议版本与启动方式。
- 实现真实能力协商和提交／取消语义。
- 复用通信载体，覆盖缺失能力的可读返回。

## 可独立分工的工作

1. 验证候选 CLI 的实际协议。
2. 实现 ACP 适配及产品描述。
3. 完成受控真实 Turn 与复用检验。

这些分工供 Leader 判断，不要求按步骤建立 WorkItem。紧密耦合的实现应由同一责任单元完成。

## 不在范围内

- 不假定所有 ACP 实现能力一致。
- 不要求 ACP 取代 Codex 专用协议；不伪造原生身份。

## 完成证据

- 新增产品无需改 Task 核心。
- 取消、恢复和身份按照实际支持呈现。
- 一次真实输出可沿现有 Turn 结果路径保存。

验收场景：S11、S12、S24、S35。场景定义见[统一验收说明](../../reference/acceptance-scenarios.md)。
