# T11｜按使用边界热插拔

硬依赖：T04、T09。

## 交付目标

支持能力安装与实现替换，同时让进行中调用和长期 Session 按各自使用边界稳定结束。

**完成状态：** 新能力及时可见；新调用或新 Session 采用新实现；既有工作、配置和结果不被隐式改写。

## 责任范围

- shadow 注册、切换新选择、drain 和 effects 回收。
- 长期 Session 固定必要状态型依赖。
- 普通停用、撤权与代码保留分别处理。

## 可独立分工的工作

1. 实现短调用替换。
2. 实现 Session 使用边界。
3. 验证注册失败、历史结果读取和可清理代码。

这些分工供 Leader 判断，不要求按步骤建立 WorkItem。紧密耦合的实现应由同一责任单元完成。

## 不在范围内

- 不做通用透明 live handover。
- 不热替换存储 schema 或核心权限契约。

## 完成证据

- 旧 Session 的后续 Turn 默认仍用旧实现，新 Session 用新实现。
- 同 Session 可通过稳定桥调用新增短工具。
- 历史 Candidate 不要求保留完整旧插件代码。

验收场景：S14、S25、S35、S37、S42、S45。场景定义见[统一验收说明](../../reference/acceptance-scenarios.md)。
