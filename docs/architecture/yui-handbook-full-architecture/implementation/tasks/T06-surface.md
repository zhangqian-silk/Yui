# T06｜统一 CLI 与 Web 入口

硬依赖：T03。

## 交付目标

使所有交互面只负责输入、展示、调用与订阅，并以 Operator 和 Task Leader 为两个主要对话目标。

**完成状态：** 同一操作在 CLI、Web 和 Agent 工具中行为一致，页面不维护额外 workflow 状态。

## 责任范围

- 对接 Context 和能力描述。
- 显示当前 Role 配置与实际执行配置的区别。
- 允许简单命令与受控面板贡献，支持断线补读。

## 可独立分工的工作

1. 统一查询与操作返回。
2. 实现对话目标和 Task 工作视图。
3. 接入命令／面板贡献生命周期。

这些分工供 Leader 判断，不要求按步骤建立 WorkItem。紧密耦合的实现应由同一责任单元完成。

## 不在范围内

- 不重建完整 IDE 或任意前端代码插件平台。
- 不在页面加入自动恢复、评审或重试流程。

## 完成证据

- 相同业务操作经不同入口写入同一事实。
- 可选面板不可用时仍可查看 Task。
- 排队、等待和未知效果文案区分明确。

验收场景：S15、S16、S19、S20、S30、S36、S38、S46。场景定义见[统一验收说明](../../reference/acceptance-scenarios.md)。
